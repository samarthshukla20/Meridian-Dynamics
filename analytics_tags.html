Meridian Dynamics - GA4 Tag Specification

Measurement ID: G-PJLFCC1M4P | Platform: Web (index.html, team.html)

1. Global Config Tag

Tag / Method What It Tracks (Function)
gtag('config') Initializes GA4. Automatically tracks page views (page_view), session starts (session_start), first-time visitors (first_visit), 90% vertical scroll depth (scroll), and outbound link clicks (click).

2. Website & Conversion Tags (script.js)

Tag Name What It Tracks (Function)
generate_lead Tracks verified contact form submissions after successful Web3Forms response (HTTP 200). Captures lead business type.
get_started Tracks clicks on "Get Started" buttons across pricing cards. Captures the specific pricing tier and displayed cost.
view_item Tracks clicks on outbound portfolio project links (Google Play, live client sites, Vercel deployments). Captures project name and target URL.
contact Tracks direct user clicks on telephone numbers (tel:) and email links (mailto:).
select_content Tracks category switching on Projects tabs (Advanced Tech / Client Sites / Ongoing) and Pricing tabs (Website / Social).

3. Meridian Atlas Chatbot Tags (chatbot.js)

Tag Name What It Tracks (Function)
chat_open Tracks when the visitor opens the AI assistant window.
chat_message_sent Tracks every query submitted to Atlas, recording message length and whether it was typed or clicked from a chip.
chat_suggestion_clicked Tracks which quick starter prompt chip was clicked on the welcome screen.
chat_feedback Tracks user ratings on bot answers (positive 👍 vs. negative 👎).
