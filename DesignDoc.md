# Meridian Dynamics — Premium Minimal Website Design Document

## 01. Design Vision

Meridian Dynamics should move away from a conventional agency/SaaS-style website and become a **cinematic digital studio experience**.

### Desired feeling

**Apple-inspired restraint × premium creative studio × editorial design**

The website should feel:
- Premium
- Minimal
- Confident
- Cinematic
- Modern
- Editorial
- Image-led
- Interactive without being gimmicky

Core principle:

> **Stop designing sections. Start designing visual moments.**

The website should not try to explain everything. Give visitors enough information to understand Meridian, while letting **scale, imagery, typography, whitespace and motion** communicate the rest.

---

## 02. Core Design Principle

The new website should feel like:

> **A digital experience that makes people want to keep scrolling.**

Instead of:

> “Here is everything our agency offers.”

The visitor should experience:

**Visual → Statement → Interaction → Transformation → Work → CTA**

The site should be intentionally sparse.

### Target visual ratio

- **65% visual**
- **25% typography**
- **10% functional UI**

The current site is too information-heavy. Use fewer cards, fewer paragraphs, fewer UI elements and significantly larger visual elements.

---

## 03. Color Direction

Move from the current warm ivory-heavy palette toward a **dark graphite / black premium palette**.

### Suggested palette

| Role | Color |
|---|---|
| Primary background | `#0B0B0B` |
| Secondary background | `#111111` |
| Elevated surface | `#181818` |
| Primary text | `#F5F3EF` |
| Secondary text | `#96938D` |
| Muted text | `#66635F` |
| Meridian accent | `#C96F3D` |
| Dark accent | `#8D5236` |

### Accent philosophy

Orange should become a **signature accent**, not a dominant brand color.

Use it for:
- Small section labels
- Important words
- Tiny indicators
- Active states
- Arrows
- Small metadata
- Occasional editorial emphasis

Avoid large orange backgrounds, bright gradients, neon orange and multiple accent colors.

---

## 04. Typography

Keep the current editorial serif direction.

### Display typography

Recommended:
1. Instrument Serif
2. Canela
3. PP Editorial New
4. Cormorant Garamond
5. Bodoni Moda

**Instrument Serif** is the recommended starting point if a free font is preferred.

### Supporting typography

Use a clean modern sans-serif for navigation, buttons, labels, metadata, body copy, pricing and functional UI.

### Principles

- Very large display type
- Generous whitespace
- Tight but controlled line-height
- Minimal italic usage
- Strong serif/sans contrast
- Editorial line breaks
- No unnecessary text blocks

---

## 08. Hero Interaction

The hero should have subtle depth.

### Cursor parallax

Different image layers move slightly:
- Foreground: 8–12px
- Middle: 4–6px
- Background: 2–3px

The effect should be subtle.

### Scroll interaction

As the visitor scrolls:
1. Hero imagery moves slowly.
2. Headline subtly scales or moves.
3. Images transition into the next visual section.
4. The transition feels continuous.

## 20. Image Strategy

Images are the primary storytelling mechanism.

### Image rules

Use:
- Large images
- High-resolution photography
- Real project screenshots
- Cinematic crops
- Consistent tonal treatment
- Full-width or near-full-width visuals

Avoid:
- Small thumbnails
- Repetitive cards
- Tiny illustrations
- Generic stock imagery
- Too many unrelated visual styles

### Recommended image scale

Most major visual assets should occupy **70–95% viewport width**.

Hero imagery can be full viewport width / full viewport height.

---

## 21. Motion System

Animation should feel cinematic and expensive.

Use:
- Slow image reveals
- Clip-path transitions
- Scale transitions
- Opacity fades
- Parallax
- Smooth horizontal movement
- Text reveals
- Scroll-linked transformations

Recommended easing:

```css
cubic-bezier(.16, 1, .3, 1)
```

Avoid:
- Bouncy animations
- Constant floating elements
- Excessive rotation
- Neon effects
- Random particle systems
- Animation on every element

## 24. What Should Be Removed

Reduce or remove:
- Large hero paragraph
- Hero statistics card
- Four-card service grid
- Excessively detailed process descriptions
- Dense pricing cards
- Repetitive explanatory copy
- Small portfolio cards
- Decorative UI elements without purpose
- Excessive orange
- Excessive glassmorphism
- Generic gradient blobs
- Overly small imagery

---

## 25. What Should Be Added

Add:
- Large real project imagery
- Cinematic hero collage
- Full-screen visual sections
- Before/after interaction
- Scroll-driven storytelling
- Large project case studies
- Dark graphite visual system
- Subtle orange accent
- Large editorial typography
- Minimal navigation
- Selective cursor interactions
- Large typographic statements
- Image-driven services
- Expandable information where detail is necessary

---

## 26. Visual Hierarchy

Every page section should have one dominant element.

| Section | Dominant element |
|---|---|
| Hero | Headline |
| Statement | Typography |
| Transformation | Before/after image |
| Services | Huge visual |
| Work | Project image |
| Difference | Typography |
| Process | Timeline |
| Pricing | Price |
| Contact | CTA |

Never allow multiple components to compete equally.

---

## 27. Design Test

Before adding any section or component, ask:

1. Does this communicate something important?
2. Can an image communicate it better?
3. Can the copy be reduced by 50%?
4. Does this need to exist as a card?
5. Does the interaction have a purpose?
6. Is this helping the visual hierarchy?
7. Would removing it make the page stronger?

If the answer is no, remove it.

---

## 28. Final Experience

The redesigned Meridian Dynamics website should feel like:

**Luxury editorial + Creative digital studio + Technology company**

It should not feel like:

**SaaS landing page + template marketplace + AI-generated agency website**

The visitor should experience the brand through:

**scale + imagery + typography + motion + restraint.**

---

## 29. Final Design Statement

> **The next Meridian should feel less like a website and more like an experience.**

The goal is not to show visitors everything Meridian can do.

The goal is to show them enough to make them think:

> **“These people know how to build things.”**

And then:

> **“I want them to build mine.”**
